# Estado del trabajo

Los documentos de esta carpeta describen dónde está el proyecto. Los de `archivo/` son versiones
superadas de los mismos documentos, conservadas porque el registro de cómo cambió el juicio sobre
el propio trabajo es parte del trabajo.

| documento | qué responde |
|---|---|
| `DONDE_ESTAMOS_9sep.md` | en qué estado está cada artículo, hoy |
| `MADUREZ_Y_PUBLICACION.md` | qué está listo para enviar y a dónde, con las restricciones reales |
| `GENUINO_Y_PENDIENTE.md` | qué resultados son nuestros y cuáles tienen precedente publicado |
| `AUDITORIA_precedencia.md` | cada afirmación con su estado de comprobación bibliográfica |
| `CORREOS_que_pedir.md` | a quién se ha escrito, qué se le pide y qué cuesta al otro |
| `LISTA_BUSQUEDA.md` | qué fuentes faltan por conseguir y dónde están |
| `CITAS_Y_CORREOS.md` | las citas completas de lo que falta |
| `OPENETRUSCAN_comparacion.md` | comparación con el proyecto vivo más parecido al nuestro |
| `VOLUMEN_2025_INDICE.md` | índice del volumen de referencia del campo y qué nos afecta |
